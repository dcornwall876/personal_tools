◇Personal Tools Privacy-conscious utilities

YOUR OWN DIGITAL TOOLKIT

Useful tools.
Less unnecessary data sharing.

A small collection of utilities hosted on your domain. A collection of practical tools for creating, checking and understanding your digital setup.

01 / CREATE

QR Code Generator

Turn a link or short text into a QR code. The content is encoded in your browser.

Enter text or a URL to begin.

The QR library is downloaded from cdnjs. The text you enter is not sent to cdnjs, but your browser contacts that CDN to load the library.

02 / GENERATE

Password Generator

Generate random passwords using your browser's cryptographic random number generator.

Your password will appear here

Generated locally. Nothing is uploaded.

Use a reputable password manager to store passwords. Do not reuse passwords across services.

03 / INVESTIGATE

DNS Lookup

Query common DNS record types using Cloudflare's DNS-over-HTTPS resolver.

Enter a domain to view its DNS records.

The query is sent from this site's Cloudflare Function to Cloudflare's public DNS resolver. Do not use this tool to submit private internal hostnames.

04 / EMAIL SECURITY

Email Domain Security Checker

Review email authentication, mail routing and transport-security records for a public domain.

Enter a public domain to inspect its email security configuration.

This tool checks public DNS records and retrieves the MTA-STS policy over HTTPS. Live SMTP TLS negotiation is explicitly marked “Not tested”: the checker does not open an SMTP connection or verify a live STARTTLS handshake, negotiated TLS version or mail-server certificate. It does not send email or guarantee message deliverability. Domain names and DNS lookup information are sent to this site’s Cloudflare Function and Cloudflare DNS. DKIM selector discovery is best-effort, not exhaustive.

05 / REVIEW

Browser Privacy Check

Review a few privacy-related browser settings. This is an informational check, not a full anonymity or leak test.

Select “Check this browser” to inspect available browser signals.

Checks run locally. Browser settings and signals are not a definitive measure of privacy or security.

06 / NETWORK

IP Information

View the public IP address and limited connection information visible to Cloudflare for this request.

Select the button to retrieve the connection information.

Your IP address is personal data. This endpoint returns information about the current request and does not intentionally store it. Your hosting provider may still process operational logs under its own policies.
